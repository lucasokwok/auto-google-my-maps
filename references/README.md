# Implementação pública de referência

O projeto Red Fleet Stations My Maps Updater serviu para consultar a sessão persistente do Chromium, a abertura do menu da camada e o uso do seletor de arquivos do Google. [Repositório de referência](https://github.com/jlanza/red-fleet-stations-mymaps-updater)

Para consultar uma cópia local a partir da raiz do projeto, use o caminho abaixo.

```bash
git clone https://github.com/jlanza/red-fleet-stations-mymaps-updater.git references/red-fleet-stations-mymaps-updater
```

O diretório da referência é ignorado pelo Git. A revisão consultada foi `f9ee0a7`. O fluxo de atualização por correspondência segue a ajuda oficial do My Maps. [Ajuda oficial do Google My Maps](https://support.google.com/mymaps/answer/3024836?hl=pt-BR)
